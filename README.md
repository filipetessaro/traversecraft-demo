# Traversecraft Demo

Windows demo of **Traversecraft**, predicted, replicated traversal for Unreal Engine 5.6 to 5.8, on the Character
Movement Component and Mover. Vault, mantle, climb, ladders, hanging, slide, wall run, ziplines, ropes and co-op boosts.
Shipping build with UE 5.8.

**Download:** [TraversecraftDemo_Win64.zip](https://github.com/filipetessaro/traversecraft-demo/releases/latest/download/TraversecraftDemo_Win64.zip)
(719 MB). Windows 64-bit, DirectX 12. No engine needed.

Unzip it anywhere and run `TraversecraftDemo.exe`. You start in a rail yard in an old factory town; every move is on the
way, and `HOW_TO_RUN.txt` in the zip lists them in order.

| Key | What it does |
|---|---|
| WASD or left stick | Move |
| Mouse or right stick | Look |
| Space or A | Jump. In front of something, the jump traverses it |
| E or left shoulder, held | Help a teammate: brace for a boost, or kneel at an edge to pull them up |
| V or right stick click | Third or first person |
| F2 | The other map: the showcase, or the plain course from the plugin's example |
| F3 | Call a partner for co-op, or send it away |
| Esc | Quit |

Traversecraft is a technical system. The showcase art (Abandoned Factory Buildings and Construction Site vol. 1 and 2,
from Fab) is in the demo only, not in the plugin. The plugin comes with the plain example course (F2) and example
animations meant to be replaced with your own or Epic's Game Animation Sample.

The demo runs on one machine. How it behaves online, at 150 ms of lag and 5% packet loss, is in the docs.
